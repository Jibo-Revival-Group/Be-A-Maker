This folder contains two items: the Xcode project, which you can explore and customise as you like. It's essentially an uncompressed app or its source code.  The other item is the .ipa file. If your primary goal is to install the app on your iPad, this is the file you need.  This app is iPad-focused because it requires a large display which a phone simply doesn't provide and looks strange. To install it, use AltStore and sideload the app to your device using the .ipa file. (Remember to use Maker IOS.ipa)}
